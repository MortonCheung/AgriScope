# AgriScope Decision 前端产品化交付

这是 `2f7af6b` 基线的历史交付记录。当前正式收口、Final Model / Daily 接入与冻结验收以 [FRONTEND_INTEGRATION_REPORT.md](FRONTEND_INTEGRATION_REPORT.md) 为准。

本轮在现役 AgriScope 上接入种植选择流程。保持暖白纸面、宋体标题、直角控件、细线图表与现有空间转场；未重设计首页、辽宁地图或研究页面。两个只读子 Agent 分别比较产品信息架构与模型契约后，采用独立城市工作页，避免把决策模式塞进成熟研究窗口。

## 已完成的产品路径

城市窗口安静文字入口 → `/cities/:cityId/decision?view=input` → loading → 单方案主角 → 收益与风险 / 两方案比较 / 依据 → 现有 `/scenario-lab?mode=decision` 的压力实验。

必要条件为面积、预算、最早种植、最晚上市与偏好；作物、上市下限、实际亩均成本/亩产渐进展开。没有隐藏默认请求。历史样例在次级展开中；正式 API 模式自动移除历史样例并调整输入说明。

- 首层：作物、面积、上市窗口、短理由、收益范围、主要限制与推荐层可信程度；移动端把可信程度和成本缺项放在收益之前。
- 详情：价格/利润三点情景、ROI 区间、保本价、输入口径、HRI / 市场风险 / 气候暴露细线刻度。候选原始置信度后置，避免盖过整体推荐折扣。
- 比较：两方案/两窗口、共享收益尺度、逐指标对照，缺失保持为空；移动端逐行读取，无宽表撑破页面。
- 压力：正常、市场转弱、生产受损、综合压力；保留原方案与固定尺度，展开后可对照价格 -10%、成本 +20%、延迟 7 天和自定义参数。场景/参数在 URL，刷新和后退可恢复。
- 依据：进入既有 A1.3 / A6 canonical 研究，明确其是市场背景，未冒充当前决策利润的输入证明；支持未来模型 input 关联类型。
- 异常：loading 可取消，数据不足/输入不足/模型错误可修改，输入不足自动展开补充条件；低可信、proxy、无明确赢家、情景及部分结果可以同时出现。

城市 → 决策 → 返回城市保留一个 Canvas；Esc 保留既有历史回退语义，上一级仍通过纸面收回与相机回省域退出。原有暴雨推演默认三组表和可靠性门控仍保留，顶部仍为研究 / 报告 / 推演 / 关于，未新增一级入口。

## 数据和最终模型接入

4 个旧模型真实快照，价格、收益、风险及分数保持源值；来源与快照 SHA256 可验证。基准推荐层 37.4/D、候选 82.6/A、成本缺项、利润异常偏高、无明确赢家等限制保留。自定义条件只做确定性公式比较，不复刻推荐引擎、不随机造数、不把面积变化写成价格变化。

契约与 Provider 边界见 API_CONTRACT_V0.md、MOCK_DATA_MAP.md。修改 `.env.local`：

```dotenv
VITE_DECISION_PROVIDER=api
VITE_DECISION_API_URL=/api/decision
```

重启开发服务或重新构建，即使用 HTTP Provider。原生 Final Model Schema 在 Provider adapter 中转换，组件不改。15 秒超时、取消、响应校验和条件一致性检查已就绪。失败不会回退 Mock。

仅请求存 sessionStorage，不缓存结果；刷新重新调用 Provider。新请求清空旧结果，取消和过期响应不能回填。自然语言解析以后提交同一结构并保留来源原文；本轮没有接入 LLM。
