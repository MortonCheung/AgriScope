# V4 最终产品体验合同

本合同落实2026-10-10最终施工手册，建立在本地V4 `db48827`之上，施工分支为`codex/frontend-v4-final-experience`。这是产品持续维护的工程约定，不替代Runtime研究结论与模型合同。

- 全局一级入口按主页、决策、报告、关于排列；品牌与Back/Forward/Up在同一稳定Header。三箭头常驻，仅切换disabled；局部抽屉关闭不等于页面返回。
- 主页以地图与最新已发布市场观测为中心。六城身份色不表达风险。正式selection由省域URL驱动，hover独立。年度农业和气候留报告或按需依据。无省均价时显示真实市场名，价格始终附单位、来源、观测日期。
- 决策与报告使用出版物纸面、左侧目录、中央工作区、右侧当前结果或依据；同城切换内容不卸载纸面或重播整页动画。
- 决策目录只有经营计划、市场观察、短期市场比较、上市窗口情景。作物及已有指标直接选择，周期滑块只能选能力API登记节点。用户输入核算不包装成模型预测；未支持城市不借城模型。
- 未选期限的全局上下文为null，不自动给主页或经营计划写14天。上下文可保留7/14/30/60/90/120/150/180；当前模块的真实能力决定可操作节点，不能把长期节点提交到短期路径。期限与作物必须在URL、请求、结果及当前摘要之间一致；过期响应不得覆盖新选择。
- Opening采用摄影机推进与地块组装共享的一条进度，约2–3秒，最终机位等于正式省域机位；一个Canvas，可skip、reduced motion与卸载取消。
- Daily查询只读正式快照，不触发采集。观测日期、采集证据、快照生成、Runtime发布、模型报告生成分别表达。研发资产经专用发布进入Runtime，模型和研究保持原可信边界。

详细源码审计、阶段执行证据及临时媒体遵循工作区冻结架构，保存在外层archive；正式运行不读取archive/reference。所有正式研究文章、图表、来源及Cross-city/Synthesis保留。阶段测试与最终全量验收必须使用本轮新结果。
