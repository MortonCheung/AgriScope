# AgriScope 前端 V4 设计与实现

施工基线：`5035668bab21785d392900f155ad548d2ece06ce`。本轮围绕同一张辽宁地图，把观察、经营核算和研究证据连接起来。保留现有正式模型、研究文章、研究表和运行资产。

## 1. 状态与 URL

- `/`：草稿 → 点击进入 → 组装与摄影机环绕 → 完成 → `/liaoning`。每次重新进入首页都重置开场；减少动效时直接提供进入链接，但不自动离开首页。
- `/liaoning`：全省观察，无城市选中。首次进入、旧会话存储、无参数刷新均不补 `city` 或 `horizon`。
- `/liaoning?city=dandong`：锁定丹东，两侧切为丹东农业与城市摘要。连续选城仍在同一路由，不进入研究页。返回全省删除选城参数。
- `/cities/:cityId` 和 `/cities/:cityId/research/:moduleId`：同一研究外壳。沈阳使用既有策展树；五城使用真实模块索引。外壳和退出规则一致，研究颗粒度保持原资产差异。
- `/cities/:cityId/decision`：经营计划是默认工具。独立短期、长期能力决定额外工具是否开放。`/decision` 未指定城市时显示六城选择入口。

`useContextUrlSync` 只做 URL → store，没有反向 Effect。显式选择作物、点击研究、点击决策才写 URL。路径中的城市优先于查询参数。共享字段为 `city / crop / horizon / as_of`；地图 URL 只表达观察对象，经营字段保留在会话状态中。

`agriscope.context.v4` 不继承旧版默认沈阳。经营会话按城市、作物保存输入、已核算条件和方案 A；研究返回和刷新恢复已核算结果。有效编辑即时重算，无效编辑撤销有效快照；缺输入、零除数与溢出不会留下旧利润或写入 Infinity。

## 2. 观察布局与指针规则

桌面是左侧农业观察、中间完整沙盘、右侧摘要与行动入口。省域主区提供六城各自最近年度的主要作物，明确年份与统计范围不同；气候摘要使用共同完整年的六城范围，不造全省总量或均价。

选城后左侧显示真实主要作物面积与本城市场状态，右侧显示完整年降水、年均温和经营入口。技术版本、表路径与研究方法在证据层展开。五城缺日度市场时说明本城尚无该观测，不借沈阳行情。

Hover 只改变地块抬升、描边和底部简要预览，不改变锁定的 Inspector 或 URL。鼠标离开清 Hover，保留 Selected。地图 Mesh 和六城列表走同一选择函数。DOM 的空白舞台不截获地图点击，侧栏与按钮显式恢复交互。

≤900px 使用固定地图舞台和下方信息 Sheet；≤600px 信息单列。手机和 Opening 共用 `43dvh` Canvas 舞台，防止开场终帧接省域时改变投影比例。研究模块列表在手机仍可滚动选择，正文独立滚动；沈阳树沿用有键盘支持的抽屉。

## 3. 导航与退出

全局保留真实后退、前进。城市相关页面只有一个“返回城市概览”，没有第二个上一级或嵌套关闭按钮。研究页返回 `/liaoning?city=<本城>`；决策页同样返回本城选择。

Esc 优先关闭证据抽屉和研究树抽屉；没有抽屉时返回城市概览。在地图页先撤销 Hover，再撤销 Selected。浏览器 Back/Forward 恢复真实 URL 与选城；深研究链接刷新仍是同城、同模块。绘制层只有一个长期存在的 Canvas，路由不以 key 重建它。

## 4. 摄影机与生命周期

轨迹使用已安装 three 的 centripetal `CatmullRomCurve3`，24 个环绕控制点、1200 段弧长映射，position 与 target 独立。统一 4800ms 时间轴同时驱动下落与镜头。方位展开累计 360°，地图根节点 Y 旋转始终为 0。相机根据真实地图半径和 Canvas aspect 取景，末帧严格等于 `provinceView`。

详细位姿、视锥、速度和真实顶点证明见 [CAMERA_PATH_PROOF.md](CAMERA_PATH_PROOF.md)、[RESPONSIVE_CAMERA_FIT.md](RESPONSIVE_CAMERA_FIT.md)。证明与浏览器录屏是两份独立证据，不以数学证明替代真实播放。

开场可跳过，跳过按钮自动获得焦点；卸载取消时间线，重复完成不重复导航。CameraControls 的同位姿 Promise 也会结束 `cameraMoving`，不会等待永远不触发的 rest。Demand 渲染只在运动时请求帧；工作台隐藏地图时关闭相机输入与指针视差监听，保留同一个 WebGL 上下文。

## 5. 六城经营与真实能力

新增只读 `/api/observations`，直接读 `runtime`。沈阳生产为 8 农业区县、2018–2024，五城为各自年鉴覆盖作物；千公顷显式换公顷。历史气候只提供 2010–2025 完整年，2026 截尾资产不作全年观测。缺资产返回不可用与空序列，未知城市拒绝，不跨城替代。

六城均提供生产结构、历史气候、盈亏平衡、用户情景和方案 A 对比。输入面积、亩产、每亩成本、假设销售价、可销售比例；成本、亩产与假设销售价不自动采用城市统计数字。

计算：可售数量 = 面积 × 亩产 × 销售比例；收入 = 可售数量 × 假设价格；成本 = 面积 × 每亩成本；利润 = 收入 − 成本；保本价格 = 每亩成本 ÷（亩产 × 销售比例）；保本亩产 = 每亩成本 ÷（假设价格 × 销售比例）。敏感性分别改变价格、亩产、成本 −20% 至 +20%，不是事件概率。零值使相关保本项不可计算；零成本 ROI 不提供有限百分比假象。

短期模型仍只开放沈阳、朝阳，正式预测跨度 7/14/30；沈阳长期是探索参考，其他五城不开放长期模型。新增 `features` 保留旧 capability 字段，旧 `supported` 仍是 Final 价格推理条件。`validated_model=true` 当且仅当 `result_type=VERIFIED_MODEL`；确定性公式和用户情景不标成经过验证的模型。

完整来源、范围与逐城功能见 [CITY_DECISION_CAPABILITY_MATRIX.md](CITY_DECISION_CAPABILITY_MATRIX.md)、[V4_OBSERVATIONS_API.md](V4_OBSERVATIONS_API.md)。没有训练模型、修改 Registry、改变研究结论或发布研发源资产。

## 6. 研究、证据与异常

经营页“为什么”打开本城真实观测和已有 Evidence Drawer；完整研究链接保留四要素，五城可进入本城已发布模块，不因缺沈阳策展点而被拒绝。返回经营页恢复输入与结果；不同城市不借用另一城正文或利润。资源 hook 用 key 和请求清理隔离迟到响应，缓存命中首帧也不展示上城正文。

讲解模式及重复 ContextBar 按迁移矩阵退役，专用快捷键、轮询、样式和测试一并删除。研究内部的字段名改为既有中文指标标签，未支持状态说明缺什么数据；原研究正文与科学限制保持不变。

几何失败、WebGL 初始化失败或 context lost 时显示明确地图恢复入口，六城列表仍可操作。农业观测失败明确显示错误，撤销观测数字；经营公式仍依赖用户输入。正式模型失败保持不可用，不回退 fixtures/mock。缺图、缺表、缺价格、缺完整年分别处理，不能互相填补。
