## 全局规则（后续每页施工时自检）

```text
1. 开发状态（已开放 / 待开放 / 当前完整样板 / 计划研究 N 城）→ 一律删除
2. 与标题或导航重复的 label → 删除
3. 数字只看它是否帮助当前任务；不帮助就是噪音（§83）
4. 数据口径、来源、限制、假说与事实之分 → 一律保留，且不可压缩
5. 空态与错误态必须说清"现在能做什么"
```
