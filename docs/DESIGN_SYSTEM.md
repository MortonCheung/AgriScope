# 设计系统（DESIGN_SYSTEM）

方向：**研究出版物 × 数据产品 × 空间化数字展览**。
参考 Claude / Kimi / Apple 的克制与留白，但形成自己的暖白研究体系。

## 1. 视觉原则

- 暖白纸面、近黑墨色、暖灰层级、极浅分隔线。
- 大留白、大标题、大数字、大图；不把每段内容都塞进卡片。
- 彩色首先承担数据变量语义；不因为页面空而添加装饰性彩色。
- 深度来自材质对比与细线，不来自阴影堆叠与发光。

### 禁止

蓝紫科技大屏、赛博朋克、霓虹、HUD、大量 Glow、AI 紫、科技蓝渐变、
满屏玻璃拟态、智慧农业驾驶舱、农业绿色模板、麦穗背景、田野图库堆砌、满屏圆角卡片。

## 2. 色彩

| 用途 | 令牌 | 值 |
|---|---|---|
| 纸面 | `--ag-paper` | `#f7f5f1` |
| 版面抬升 | `--ag-paper-raised` | `#fcfbf8` |
| 版面下沉 | `--ag-paper-sunken` | `#f0ede7` |
| 近黑 | `--ag-ink` | `#1a1917` |
| 次级文字 | `--ag-ink-soft` | `#4a4641` |
| 说明文字 | `--ag-ink-muted` | `#736d65` |
| 弱化文字 | `--ag-ink-faint` | `#9c968c` |
| 分隔线 | `--ag-rule` / `--ag-rule-soft` / `--ag-rule-strong` | 近黑 12% / 7% / 26% |

数据变量语义色（`--ag-data-*`）：`rain #4e6e8e`、`temp #b4633a`、`humidity #6e8a85`、
`soil #8a6f4a`、`wind #7e8ca0`、`radiation #bf9a4a`、`price #1f1d1b`、`volume #7c8a63`、
`extreme #a8402e`、`model #6b6670`、`null #9c968c`。

证据/状态语义：A `#2f3b33`、B `#4a5460`、C `#6d6152`、D `#6b6670`、Unsupported `#9c968c`。

**来源三态**（实际观测 / 模型估计 / 情景模拟）用线型 + 透明度区分：实线 / `dash 6 4` / `dash 2 5`。

## 3. 排版

- 展示层：`--ag-font-display`（Songti SC / Noto Serif SC / Georgia）——出版物感，仅用于大标题与关键数字。
- 正文与控件：`--ag-font-text`（系统无衬线）。
- 标签与元信息：`--ag-font-mono`。
- 字号阶梯：display（clamp 3.4–8.5rem）→ hero → section → title → lead → body → small → meta → micro。
- 大标题可以非常大；正文行高 1.78，测量宽度 ≤66ch。

## 4. 间距与栅格

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128 / 176 px。
- 容器：`--ag-content-max: 1360px`，`--ag-gutter: clamp(20px, 4.5vw, 76px)`；长文用 `.ag-container--prose`。
- 章节间距 `--ag-section-gap`，章节之间用 1px 细线而非卡片边界分割。

## 5. 圆角与控件

- 圆角克制：`--ag-radius-sm 3px`、`--ag-radius-md 6px`、`--ag-radius-pill 999px`（仅 chip/badge）。
- 主按钮为墨色实底 + 纸色文字；次按钮为细线描边；不使用彩色渐变按钮。

## 6. 动效

| 令牌 | 时长 | 用途 |
|---|---|---|
| `fast` | 0.18s | 悬停、按下 |
| `normal` | 0.28s | 面板/切换出现 |
| `slow` | 0.44s | 内容层进入 |
| `route` | 0.42s | 路由转场 |
| `camera` | 0.82s | 相机移动/推近 |
| `chartReveal` | 1.2s | 曲线沿时间绘制、标注逐条出现 |

- 统一缓动 `cubic-bezier(0.16, 1, 0.3, 1)`。
- 必须支持 `prefers-reduced-motion`：退化为瞬时，而不是换一个动画。
- 验收问题：**删掉这个动画后，用户是否更难理解数据或空间关系？** 若"不会"，就不应该有它。

## 7. 图表规范

- 网格线用极浅分隔色，零线用虚线，标注线用强调色但克制。
- 坐标轴标签用等宽字体、10px；数字使用 `tabular-nums`。
- 每个图表必须同时给出：标题、说明、来源文件名、证据等级、来源三态标注。
- 允许用户重新观察研究：品种/变量/滞后窗/时间至少有一个可切换维度。

## 8. Do / Don't

**Do**：大留白；细线分割；大标题 + 大数字；真实数据驱动；阴性结果正面表达；来源可追溯。

**Don't**：AI 紫与科技蓝；满屏玻璃卡片；无意义飘动与粒子；把方法学名词堆在第一屏；
把阴性结果写成"没有发现"来淡化；用假数值让页面好看。
