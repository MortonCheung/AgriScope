# Decision 产品化行动步骤

执行阶段严格对应任务书，完成后在 FRONTEND_FINAL_REPORT 中记录验证证据。

1. 现役全目录扫描与基线运行（已完成；CURRENT_FRONTEND_AUDIT）。
2. 固定视觉/动画基线和 DO_NOT_TOUCH（已完成；VISUAL_BASELINE）。
3. 本地 reference 分类清点和关键实现阅读（已完成；REFERENCE_USAGE_REPORT）。
4. 历史外部参考实站研究，记录访问范围与局限（已完成；REFERENCE_USAGE_REPORT）。
5. 信息架构：城市安静入口 → 同城市决策工作页；结果/收益风险详情/两方案比较/依据；压力进入现有推演。另一方案“直接改城市窗口为研究/决策双模式”因侵入成熟空间而不采用。
6. Contract v0：请求、候选、方向、整体可信程度、字段来源、风险、压力、版本与异常。轻量运行时校验；Provider 唯一入口。
7. 选定真实 v2 快照静态导出；Legacy 只返回匹配请求；自定义条件走确定性 Mock，明确情景与实际使用假设。无随机数、无浏览器模型复刻。
8. 渐进条件表单 → loading → 一个候选主角。保留自然语言输入来源接口，暂不接 LLM。
9. 收益/风险详情：三点价格与利润情景、ROI、保本价、HRI/市场风险/气候暴露线性刻度、可信程度与数据质量。
10. 两方案逐指标比较；同屏同尺度；移动端逐行读数；支持替代窗口。
11. 正常/市场转弱/生产受损/综合压力；详细参数渐进展开；真实 stress 原样，组合/自定义公式标记演示；上市延迟不伪造影响。
12. no_data、输入不足、模型错误、低可信、proxy、无明确赢家、情景、部分结果等可组合状态。
13. 查看依据进入既有 canonical 研究；区分历史背景与决策输入依据，不改原研究结论。
14. Desktop 1920、MacBook 1440、笔记本 1366、Tablet 768、Mobile 390；动画、键盘、触控、刷新/返回、性能实测。
15. 全部旧测试与有意义的新测试、typecheck、build、完整性、UI verify。
16. 旧截图回归和新页视觉一致性复核；写最终交付及真实 API 替换说明。

终止条件：主流程与主要状态可操作、快照来源可追溯、Provider 可替换、模型目录未修改、原研究验证保持通过、响应式与视觉复核完成。普通技术选择自主推进，不逐阶段等待确认。
