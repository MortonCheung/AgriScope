## 实现行为

### 北京时间

`BeijingClock` 固定使用 `Asia/Shanghai`，显示 `MM-DD HH:mm:ss`，每秒读取浏览器当前时间。数字使用既有等宽字体与 tabular-nums，时钟不使用 FlipValue，也不逐秒播报。

隐藏时暂停秒定时器；恢复可见或焦点立即同步，卸载清理。秒级状态只在时钟自身，父纸面、地图、行情计算和 API 不随秒变化更新。

### 真实行情时间

数据状态只取当前地区、当前价型的实际记录：

- 最近观测来自 `observation_date`；
- 采集时间来自 `collectedAt`；
- 发布时间来自整包 `published_at`。

没有记录时显示本地缺项，不借 coverage 中其他口径的日期。新鲜度按北京时间日历日差区分今日、近期（1–2 天）、历史（3–7 天）、较旧（超过 7 天）。防御性组件不把未来日期说成今日。

V2 只有采集日期时仅展示月日，不补造小时；无发布时间保留空证据。新鲜度只在北京日界及页面恢复时重算，与秒钟独立。

### 七地区、四价型与来源

六个城市沿用原地图选择；省级使用原返回/取消城市选择入口。四种价格口径各自独立：批发、超市、集市、监测均价。省均价不会被标为城市批发价。

城市切换保留用户当前口径、商品和趋势选择，不隐式切换到其他口径。用户可以主动查看缺项；缺项不显示价格或趋势，不跨城市、口径补数。

正常纸面价型按钮为两列，避免长标签拆字；短手机（宽≤600、高≤700）在固定操作区内使用单行原生横向价型滚动，各按钮至少 56×44。键盘焦点主动将按钮带入视窗，焦点轮廓在按钮内；横向滚动与下方数据纵向滚动分开。

右纸按当前地区所有记录的真实 `id/name/url` 去重，多个来源全部展示；左纸逐商品直接链接该记录来源。V2 未提供来源时不以配置网站冒充观测来源。

单期历史显示“最新”，不把兼容的 change_percent=0 当成真实持平。无可比较样本时涨跌统计显示破折号。极小正价格显示 `<0.01 元/kg`，避免格式化成虚构 0.00。

### 请求稳定性

60 秒整包检查保留。页面隐藏不请求，恢复焦点/可见立即检查。正在进行的请求合用，同内容（包括集合/对象键重排）不通知行情订阅者。

HTTP 与 store 都有 10 秒绝对截止；fetch、JSON body 或加载实现忽略取消时仍可恢复。失败保留最后完整验证成功的代；旧请求迟到不能覆盖后来的请求。合法后端回滚仍可接受，不以发布时间单调增加阻止回滚。

请求健康状态通过独立订阅呈现“暂时无法获取更新”，该订阅不发请求、不建轮询。

## 最终 API 契约

端点：`GET /api/market/display`，一次完整 JSON，成功后原子替换。

V3 必需：

- `schema_version: "3"`；
- `products`：黄瓜、甘蓝、青椒、尖椒、土豆、西红柿、茄子、大白菜；
- `price_levels`：wholesale、supermarket、retail_market、market_average；
- `published_at`：有效带时区 ISO8601 或 null；
- `records`、`missing`、七地区 `coverage`。

每条记录必需：region、product、price_level、有限正 price、真实 observation_date、带时区 collectedAt、有限 change_percent、1–4 个按日期递增的正数 history、unit="元/kg"、source{id,name,url}。历史末项须与当前价/日期相同，涨跌须与相同记录历史一致；单期涨跌仅接受兼容的 0。

missing 必需包含 region、product、price_level、reason="no_local_observation"。记录和缺项完整覆盖 224 格，不能重复、缺格、混入其他地区/价型。

coverage 每地区必需：collection_status=configured/not_configured、available_records、total_records=32、latest_observation_date、latest_collected_at。数量及最新时间与实际记录一致；采集时间按真实时刻比较，兼容不同 ISO 时区表达同一时刻。

`configured` 不表示定时任务已启用，也不表示今天采集成功，前端没有生成这类成功宣称。

V2 严格兼容三口径、168 格与 scheduled/not_configured 状态，不补造第四口径、来源或发布时间。V1 与未知 schema 拒绝，API 失败不切换静态数据。未来额外字段允许，但已约定字段语义不变。

## 联调与限制

目前实际读取本地 127.0.0.1:8787 返回旧 V1，其他现有 IPv6 服务的 display 路由为 404；因此未完成正式 V3 运行 API 联调。前端会拒绝 V1、显示真实缺项与更新失败提示。

只读核对后端独立开发分支发现两处契约差异：其 V3 时间校验尚允许仅日期，coverage 最新采集仍按字符串取最大值。前端按本任务要求完整 ISO 和真实时刻校验；后端若输出日期精度或错误最新时间，整包会被拒绝。

真实七地区采集覆盖、每日任务启用、最新发布代、API 服务切换属于后端独立任务。本轮不修改后端、不补造价格，也不声称这些外部环节已验证。

研究检查在隔离 worktree 临时复用已有研究资产的开发链接，只读验原始文件，未引入生产代码对外部工程路径的依赖，也未改资产内容。
