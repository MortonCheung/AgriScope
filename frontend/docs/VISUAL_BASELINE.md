# CURRENT_VISUAL_BASELINE / DO_NOT_TOUCH

实际截图与现役源码优先。暖白自然、编辑出版物、纸面档案与实体地理空间；低密度、主角明确。与传统后台和科技大屏没有接入关系。

## 固定设计事实

- paper #f7f5f1，raised #fcfbf8，sunken #f0ede7；ink #1a1917；其余层级直接引用现有 token。
- 展示字 Songti SC/Noto Serif SC/Georgia；正文系统字体；标签 SF Mono 等宽。没有新增字体。
- UI 圆角实际为 0；旧 DESIGN_SYSTEM 的 3/6px 描述已过时。
- 间距 4/8/12/16/24/32/48/64/96/128/176px；容器、边距引用现有变量。
- 墨色主操作，文字选择和共享底线；hover 仅本地反馈。
- Motion DOM 选择/状态，Three 相机空间，原生 View Transition 路由。新功能只用同一套 duration/ease。
- 图表细线、点与区间，来源边界明确，数值不滚动凑效果。

## DO_NOT_TOUCH

首页布局与字标；Opening 状态机和机位；辽宁几何、材质、灯光、hover、性能策略；单 Canvas 生命周期；城市纸面展开/收回；研究树、76 点编号、正文和数据诚信；全局导航；研究/原文双模式；暴雨推演默认内容与门控；全局颜色、字体、圆角和动画令牌。

## 新能力的延续方式

城市窗口只增加一条独立的文字入口；决策作为城市的工作页。条件与结果各有主角，不并排铺满指标。结果以一个方案、短理由、收益范围、主要风险、整体可信程度为首层。详情、比较、依据按需切换；压力测试沿用推演纸面。同一个 SVG 区间在条件切换时移动，基准保持可见；不增加装饰性三维。

## 一致性验收

旧页面截图保持；新页无卡片墙、渐变、发光、胶囊控件或新字体。移动端逐项比较，图表缺失明确，五档屏幕无溢出。减少动效瞬时，所有操作键盘可达，返回恢复条件与选中方案。

## 本轮已验证的窄屏例外

既有首页在 390px 字标越出视口约 2px。仅 ≤480px 用现有字号令牌与页面边距计算上限；桌面字标、字体、字距、首页结构和相机不变。五档回归已确认修复。
